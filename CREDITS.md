# Credits and upstream projects

PrismSpace builds on ideas and code from the Android virtualization ecosystem.

Primary upstream lineage:

- ALEX5402/NewBlackbox
- FBlackBox/BlackBox
- asLody/VirtualApp

Related projects that influenced the broader technical space include SandHook, VirtualXposed, DroidPlugin, LSPosed/LSPlant, and Android native hooking libraries.
